# academic-arch-2

Учебные материалы по трём курсам в формате Typst → PDF.

## Курсы

### `ais` — Архитектура информационных систем

Курс о том, как проектировать backend-приложения, которые не разваливаются при росте команды и требований.

Первый модуль закладывает фундамент: что такое компонент и слой, как SOLID и Dependency Injection снижают связанность, как Clean Architecture фиксирует направление зависимостей во всей системе. Разбираются протоколы взаимодействия — REST, gRPC, GraphQL, WebSocket — и критерии выбора между ними. Отдельная тема — синхронные и асинхронные модели: ретраи, идемпотентность, circuit breaker, брокеры сообщений.

Второй модуль — хранилища данных: как устроены LSM-дерево и B-дерево, что такое ACID и уровни изоляции, чем транзакционные хранилища отличаются от аналитических, как работают Redis и DuckDB.

Третий модуль — специализированные индексы и поиск: инвертированный индекс, trie, bitmap, векторный поиск и эмбеддинги, приближённый поиск ближайших соседей (HNSW, LSH), геопространственные структуры (R-Tree, QuadTree, KD-Tree).

Четвёртый модуль — операционные компоненты: прокси и балансировка нагрузки, rate limiting, аутентификация и авторизация (RBAC, ABAC, JWT, OAuth 2.0, SSO), observability (логирование, Prometheus, Grafana, distributed tracing).

Курс сопровождается пятью практическими работами: проектирование API и архитектуры, реализация на выбранном стеке, расчёт нагрузки OLTP-системы, работа со специализированными индексами, операционные компоненты и OLAP.

### `olap-ib` — Аналитическая обработка данных в задачах информационной безопасности

Курс о том, как хранить и анализировать большие объёмы данных в контексте ИБ-задач.

Лекционная часть покрывает ClickHouse: архитектура колоночного хранилища, движки таблиц, семейство MergeTree, партиционирование, TTL, физический порядок хранения (ORDER BY / PRIMARY KEY), дедупликация через ReplacingMergeTree. Отдельно разбирается распределённый ClickHouse: шарды, реплики, ZooKeeper/ClickHouse Keeper, локальные и Distributed-таблицы. Также рассматриваются модели управления доступом RBAC и ABAC, и методы обезличивания персональных данных (k-анонимность, квази-идентификаторы).

Лабораторный практикум: настройка RBAC в ClickHouse, обезличивание персональных данных тремя способами (мутация, ReplacingMergeTree, ETL), аудит логов безопасности с Materialized Views, Private Set Intersection.

### `rsod` — Распределённые системы обработки данных (не активен)

CAP-теорема, консенсус, Kafka, Kubernetes, Spark, Erlang, распределённые БД. TBD.

## Требования

- `docker` — сборка PDF через контейнер Typst
- `uv` — запуск Python-скриптов (генерация архитектурных схем из YAML)

## Основные команды

```bash
make           # сборка всех PDF
make -B build  # принудительная пересборка
make watch     # пересборка при изменениях
make clean     # удалить PDF-артефакты
make list ais  # структура документа по заголовкам
```
